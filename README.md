Summary
This project addresses the challenge of identifying individuals from visual information efficiently. Manual review of surveillance footage can be time-consuming and susceptible to human error. To investigate an automated approach, I independently designed and developed a web-based system combining deep learning and computer vision to support the identification of individuals represented in a predefined dataset of fugitive profiles. The system processes both uploaded videos and live webcam feeds.

Methodology
I collected, annotated, preprocessed, and augmented a dataset containing images of known fugitives using Roboflow. I then trained and validated a YOLOv8 object-detection model using the prepared dataset. I integrated the trained model into a web application developed using HTML, CSS, Bootstrap, and JavaScript for the frontend, Python Flask for backend operations, and MySQL for managing user information and fugitive records. I also implemented user authentication and administrative record-management functionality.

Results
I developed a functional web-based identification prototype integrating the trained YOLOv8 model into a complete application workflow. The system supports identification through uploaded videos and live webcam input. I conducted functional testing and assessments covering usability, compatibility, performance, and security. The results demonstrated the feasibility of combining deep learning-based detection with web application technologies. However, the project report does not provide independently verified quantitative benchmarks for detection accuracy or inference speed.

Contribution
I independently completed this project, including the thesis documentation, system development, and implementation. My responsibilities covered the entire development process, from collecting and preparing image data to training and implementing the YOLOv8-based detection model. I also developed the web application, integrated the trained model with the Flask backend, implemented database functionality using MySQL, and developed the user-facing interface. Additionally, I carried out debugging, system integration, testing, and evaluation of the application's functionality and performance. This work provided me with practical experience in independently developing an AI-based application from data preparation and model development to web integration and testing.

Conclusion
The project demonstrates the feasibility of integrating deep learning-based object detection into a web-based identification prototype. Its limitations include dependence on dataset quality and representativeness, variations in environmental conditions, computational requirements, and potential identification bias. Future improvements should focus on more representative training data, rigorous quantitative evaluation, inference optimization, and stronger safeguards for privacy and fairness. Independently completing this project strengthened my practical understanding of artificial intelligence, deep learning, computer vision, and full-stack application development.
